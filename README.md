# Tic Tac Toe

A simple, minimalist Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features
- Two-player gameplay (Player X vs Player O)
- Minimalist, clean design
- Automatic win/draw detection
- Reset button to start new games
- Visual feedback for moves and winning combinations

## Files
- `index.html` - HTML structure
- `style.css` - CSS styling
- `script.js` - Game logic

## How to Play
1. Open `index.html` in any web browser
2. Click on any square to place your mark (X or O)
3. Players alternate turns automatically
4. Game detects wins/draws and displays appropriate message
5. Click "Reset Game" to start a new game

## Development
This project was created in the OpenClaw sandbox environment. To run locally:
- Simply open `index.html` in a web browser
- No build steps or dependencies required
